# Demo workspace. fictional data, use for practice

Everything in this folder is made up. "Maya Torres," "Vantage Media," "ShortClip," every ticket, deal, and bug ID: fabricated for the webinar. None of it touches a real company or real support data.

Point every prompt and loop in this pack at this folder first. Get a feel for the output on data that doesn't matter, then swap in your own calendar, CRM export, ticket queue, or interview notes. Each prompt file in `prompts/` and `loops/` lists exactly what to swap.
